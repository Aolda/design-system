## Overview

The component registry is a machine-readable JSON file that describes all Aolda components, their props, variants, examples, and semantic tokens. It's designed for docs, code generators, and other tooling.

[View JSON API](/api/component-registry)

## Accessing the Registry

### Via HTTP API

```bash
# JSON endpoint
curl https://ui.aoldacloud.com/api/component-registry
```

### Via jq (Local)

```bash
# Get Button props
jq '.components.Button.props' packages/ui/registry/component-registry.json

# List components by category
jq '.search.byCategory' packages/ui/registry/component-registry.json
```

## Registry Contents

<Callout type="info">
  The registry includes: component props with types and defaults, variant
  options with descriptions, real code examples from stories, semantic color
  tokens used, and sub-components for compound patterns.
</Callout>
