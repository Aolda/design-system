## SVG Generation

  <p>
    Use <code>generateAoldaLogoSvg()</code> to get copy-paste ready SVG markup for non-React contexts.
  </p>

```tsx
import { generateAoldaLogoSvg } from "@aolda/ui";

const logoSvg = generateAoldaLogoSvg();
const fullLogoSvg = generateAoldaLogoSvg({ variant: "full" });

await navigator.clipboard.writeText(logoSvg);
```
